# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use a
[private security advisory](https://github.com/constructelligence-lab/open-source-construction-tools/security/advisories/new)
and include what you found, how to reproduce it and what you think the impact is.

We aim to acknowledge reports within a week. This is a small open source project: there is no bug bounty and
no guaranteed fix time, but reports are taken seriously and credited if you wish.

## Scope

This repository is mostly documents and data, so the usual issue is a harmful or misleading instruction, or a script that does something unexpected. Both are in scope.
