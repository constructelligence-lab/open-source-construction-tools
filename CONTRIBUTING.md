# Contributing to open-source-construction-tools

Thanks for looking. This repository is a curated list of open source tools. Suggest tools with the form below. Licence, language and last commit are read from the GitHub API, so you only supply the entry and an honest caveat.

## Ways to help

- **Report an error.** Open an issue with what you saw, what you expected and where you got the expected answer.
- **Suggest an improvement.** Say what problem it solves and who hits it.
- **Send a pull request.** Small and focused is easier to review. Explain the why in the description.

## House rules

- **Honest over impressive.** If something is untested, approximate or a judgment call, say so.
- **No confidential material.** Redact project names, client names, prices and contracts from examples.
- **Sources.** Where a figure, rule or claim comes from somewhere, link it.
- **Licence.** By contributing you agree your work is released under this repository's licence (see `LICENSE`).

Questions are welcome as issues. See also the [code of conduct](CODE_OF_CONDUCT.md).
